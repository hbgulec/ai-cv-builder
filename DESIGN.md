# AI CV Builder Design System

This project uses a restrained editorial SaaS system tuned for resume creation and export.

## Voice
- Confident, calm, and practical.
- Premium, but not flashy.
- Favor clarity over decoration.
- Avoid generic AI gradients, neon glows, and overanimated glassmorphism.

## Layout
- Use a strong top-level hierarchy.
- Prefer compact, information-dense screens.
- Use cards sparingly and only when they add grouping or preview value.
- Keep primary actions obvious and persistent.
- Mobile layouts must collapse cleanly to one column.

## Color
- Base surfaces: deep slate, soft stone, and clean white.
- Accent: a single blue-indigo family for primary actions.
- Status colors: use only when semantically required.
- Keep contrast high and avoid multi-accent rainbow effects.

## Typography
- Primary UI font: Inter.
- Use clear weight contrast instead of decorative styling.
- Headings should be bold, upright, and short.
- Body copy should be readable at small sizes and line-height generous.

## Components
- Buttons: solid primary for the main action, neutral outline for secondary.
- Cards: subtle radius, thin border, minimal shadow.
- Inputs: simple, spacious, and easy to scan.
- Templates: previews should feel like product samples, not marketing art.

## Motion
- Motion should be functional only.
- Use short, subtle transitions.
- Prefer opacity and transform.
- Avoid bouncy or playful effects.

## Product Direction
- The app should feel like a serious resume tool that helps users ship a job-ready CV quickly.
- The premium impression should come from spacing, typography, and composition, not from heavy effects.
